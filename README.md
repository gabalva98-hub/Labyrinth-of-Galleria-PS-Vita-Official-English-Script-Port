# Labyrinth of Galleria: The Moon Society — PS Vita English Script Port

An unofficial adaptation of the Nintendo Switch English localization for the Japanese PS Vita release, **PCSG01246**, retaining Vita's controls and gameplay rules.

**Current release: V71 — silent continuation pages for voiced dialogue.** The patcher applies the complete patch in one step; no earlier patch is required.

## Downloads

- V71 patcher — approximately 10.6 MB, compressed ZIP.

The download contains the HTML patcher, patch data and installation instructions. No complete game archive, executable or original game texture is included. You provide your own original files.

## Requirements

- The Japanese PS Vita game, **PCSG01246**.
- VitaShell and an installed, enabled rePatch plugin.
- A recent Chromium-based browser. Desktop Chrome or Edge is recommended for the large output file.
- These two clean original files, copied from the original game folder opened as decrypted in VitaShell:

| File | Exact size |
| --- | ---: |
| Decrypted `Media.psarc` | 2,272,830,705 bytes |
| Original VitaShell `eboot.bin` | 4,715,824 bytes |

You do not need the Switch archive. Do not select files generated by an earlier patch.

## Patching and installation

1. Extract the patcher ZIP and open `GALLERIA_V71_SILENT_CONTINUATIONS.html`.
2. Select the two original files and click **Verify files and create patch ZIP**.
3. Choose a new ZIP destination if prompted. Keep the tab open until patching and downloading finish. The generated patch is over 2 GiB; keep enough space for the originals, the ZIP and the extracted files.
4. Back up any existing `ux0:rePatch/PCSG01246/` folder.
5. Extract the generated ZIP and copy its `rePatch` folder to `ux0:`. Install **both files**, even if an earlier version is already installed:

```text
ux0:rePatch/PCSG01246/Media.psarc
ux0:rePatch/PCSG01246/eboot.bin
```

6. Launch the game with rePatch enabled.

The small downloadable patcher ZIP and the generated game patch ZIP are different files. The patcher verifies the original inputs and applies its embedded patches, including the xdelta for `eboot.bin`.

The patcher runs locally and does not upload or modify your selected originals. Keep the original game installation intact. To uninstall, remove the patch's PCSG01246 folder from rePatch. To roll back, restore your previous complete rePatch folder.

## Included content

- English story and exploration dialogue, with additional pages where needed to preserve longer passages.
- Translated menus, system messages, items, equipment, skills, Donum, Pacts, petitions, quests and dungeon descriptions.
- Localized interface graphics and scene lettering adapted to Vita, retaining native Vita layouts and button icons.
- English character names and expanded labels where space allows.
- Proportional letter spacing, font adjustments and English punctuation corrections.
- Description layout improvements for skills, Donum, quests, petitions, objectives and bestiary entries.

## What changed in V71

- Silences the typing sound on **938 added continuation pages across 122 scripts** that belong to originally voiced dialogue.
- Prevents those pages from introducing the unvoiced narration sound over a conversation's voice playback.
- Keeps the typing sound in originally unvoiced narration.
- Retains the original voice triggers without repeating the voice clip on added pages.
- Preserves the reading delay used by automatic dialogue advance.

The continuation-page audio fix has been confirmed working in play testing. This does not constitute confirmation of every affected scene or a complete playthrough.

V71 includes all earlier story, interface, texture, font and description fixes. Apply it directly to clean original files; no earlier patch is required. **Always install the newly generated `Media.psarc` and `eboot.bin` together.**

## Earlier improvements retained

- Additional dialogue pages for longer English passages.
- Font and spacing corrections, including English punctuation.

- The Workshop logo and simplified public patcher interface.

## Limitations

- Original Vita tutorial images are preserved and may contain Japanese interface labels.
- Original Japanese voice recordings and audio assets remain unchanged. Advancing to another page may still stop a voice clip according to the game's normal behavior; V71 does not extend or replay that clip.
- Some interface labels and names are shortened or rephrased to fit Vita's screens. Japanese text may remain in content outside the current patch's coverage.
- Vita-specific gameplay values, controls and instructions are retained where they differ from Switch.
- Only **PCSG01246** with the specified original files is supported. Other regions and revisions have not been validated.
- The patch has **not received a complete Vita playthrough**. Successful scene tests do not guarantee that every later scene or menu is free of issues. Keep a backup of your previous working patch.

## Reporting an issue

Include the patch version, location or scene, reproduction steps and a screenshot. For text issues, quote the visible line. For an audio issue, mention whether it occurs on the first page or an added continuation page, and whether Auto, skip or backlog replay was active.

For a crash, include the Vita error code, error dump if available, the last visible dialogue and the exact point where it occurs. Please confirm that both generated files from the same version were installed. Restore your previous complete patch pair if necessary.
